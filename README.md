# Limit Order Book (LOB)

A high-performance Limit Order Book implementation in modern C++.

## Project Overview

This repository implements a fast, deterministic Limit Order Book designed for low-latency financial trading simulations.

### Key Features (Planned / In-Progress)
- **Order Types**: Limit Orders, Market Orders, Cancel Orders.
- **Price-Time Priority (FIFO)** matching algorithm.
- **Efficient Data Structures**: Cache-friendly price level tracking and $O(1)$ order lookups.
- **Benchmarking & Latency Profiles**: Nanosecond-resolution latency benchmarks for order insertion, execution, and cancellation.
